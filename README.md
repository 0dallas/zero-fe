# Detalle de construcción

Con este conjunto de documentos, la IA dispone de contexto suficiente para generar código coherente y mantener la consistencia a medida que el proyecto crece.

```
docs/

├── ARCHITECTURE.md          ← Cómo está organizado el proyecto.
├── TECH_STACK.md            ← Tecnologías y librerías permitidas.
├── CONTRIBUTING.md          ← Reglas de desarrollo y estilo.
├── PRODUCT_REQUIREMENTS.md  ← Qué funcionalidades debe tener el sistema.
├── UI_UX_GUIDELINES.md      ← Aspecto visual y experiencia de usuario.
├── ROADMAP.md               ← Orden de implementación de módulos.
└── API_REFERENCE.md         ← Resumen de los endpoints de FastAPI que consumirá el frontend.

```
