# UI Guidelines

The application should look modern.

Minimalist.

Enterprise.

Professional.

Inspired by:

- ChatGPT

- Claude

- Linear

- Vercel

---

## Colors

Primary

Blue

Secondary

Gray

Danger

Red

Background

White

Dark mode supported.

---

## Typography

Use modern sans-serif fonts.

---

## Layout

Desktop first.

Responsive.

Sidebar on the left.

Header on top.

Main content centered.

---

## Chat

The chat input is fixed at the bottom.

Messages appear centered.

User messages aligned right.

Assistant messages aligned left.

Streaming responses should appear progressively.

---

## Sidebar

Contains:

- Conversations

- Documents

- Settings

- Logout

---

## Tables

Rounded corners.

Alternating rows.

Search.

Pagination.

---

## Forms

Rounded inputs.

Clear validation.

Icons where appropriate.

---

## Buttons

Primary

Secondary

Ghost

Danger

Loading state

Disabled state

---

## Loading

Use skeleton loaders.

Avoid large spinners.

---

## Empty States

Every page should have an empty state.

---

## Error States

Every page should have an error state.

---

## Accessibility

Keyboard navigation.

Focus indicators.

ARIA labels.
